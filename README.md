# islenskur_skattreiknivel
Terminal-based calculator for taxes in Iceland. Simply enter your monthly income to see what your net salary after taxes will be. Note that if the tax brackets, personal tax credit, or pension amounts change, you will need to update these in the 'calculator.py' file.

To run the calculator, make sure your working directory is set to the project root, run `uv restore` so that your python version and other dependencies are installed, then run:

```!bash
uv run python3 calculator.py
```
